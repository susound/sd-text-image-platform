# 页面流程与导航

## 核心页面清单

| # | 页面 | 文件 | 描述 |
|:-:|------|------|------|
| 1 | 用户首页/Dashboard | `dashboard.html` | 用户概览、快捷操作入口 |
| 2 | 用户登录 | `user_login.html` | 邮箱/密码登录 |
| 3 | 用户注册 | `user_register.html` | 新用户注册表单 |
| 4 | 密码修改 | `user_password.html` | 当前密码→新密码修改 |
| 5 | 文生图 | `text2image.html` | 专业版创作面板（提示词+参数+实时进度） |
| 6 | 文生图历史 | `text2image_history.html` | 历史生成记录查询 |
| 7 | 图生文 | `image2text.html` | 图片上传与分析结果展示 |
| 8 | 图生文历史 | `image2text_history.html` | 历史分析记录查询 |
| 9 | 风格管理 | `style_management.html` | 风格模板的增删改查 |
| 10 | 管理员面板 | `admin_dashboard.html` | 系统总览统计 |
| 11 | 用户管理（管理员） | `admin_users.html` | 用户列表/创建/编辑/删除 |
| 12 | 系统配置 | `admin_settings.html` | 千问API Key等系统配置 |
| 13 | 日志管理 | `admin_logs.html` | 审计日志查询 |

## 页面流程导航图

```
[用户登录] ←→ [用户注册]
    ↓                          
[用户首页/Dashboard] ←→ [密码修改]
    │
    ├──→ [文生图] ←→ [文生图历史]
    │        ↓
    │   实时进度条 → 图片结果展示
    │
    ├──→ [图生文] ←→ [图生文历史]
    │        ↓
    │   上传→分析→JSON结果展示
    │
    ├──→ [风格管理]
    │
    └──→ [管理员面板]
            │
            ├──→ [用户管理]
            ├──→ [系统配置]
            └──→ [日志管理]
```
